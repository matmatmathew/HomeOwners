Cloud backup setup

Do this once per service. Google and Microsoft only let a website use your Drive or OneDrive after it's registered on their sites, so the first steps happen there. Each step below opens the right page. At the end you paste one ID here and tap Connect.

Google Drive

Setup steps (about 15 minutes)
  1. Open Google Cloud › New project, signed in with the Google account for your backups. Name it HomeOwners and tap Create.
  2. Open Google Drive API (check the HomeOwners project is selected at the top) and tap Enable.
  3. Open Google Auth Platform › Get started. App name HomeOwners, your email, Audience External, then finish.
  4. In the same place, open Audience › Test users › Add users and add your own Google email.
  5. Open Data access › Add or remove scopes, tick …/auth/drive.file, then Update and Save.
  6. Open Clients › Create client. Type Web application, name HomeOwners. Under Authorized JavaScript origins tap Add URI and paste:
    Tap Create.
  7. Copy the Client ID it shows (it ends in .apps.googleusercontent.com) and paste it below.

OneDrive

Setup steps (about 10 minutes)
  1. Open Microsoft › App registrations, signed in with the Microsoft account for your OneDrive, and tap New registration.
  2. Name HomeOwners. Supported account types: Accounts in any organizational directory and personal Microsoft accounts.
  3. Redirect URI: choose Single-page application (SPA) and paste:
    Tap Register.
  4. Open API permissions › Add a permission › Microsoft Graph › Delegated permissions. Tick Files.ReadWrite and offline_access, then Add permissions.
  5. Open Overview, copy the Application (client) ID and paste it below.

Your other phone or PC

After setting up here, copy a setup link and open it on your other device. That device then only needs Connect.
